# Internal notes

Working artifacts, kept for their history: the original design overview
(`design.md`) and one plan or design note per milestone and feature (`plans/`),
plus the follow-ups log from dogfooding (`plans/_followups.md`).

They record *why* things were built the way they were, as understood at the time
— they are not documentation and not an authority. Paths and decisions inside
them may be out of date. The documentation is the [README](../../README.md) and
the pages in [`docs/`](..); code comments cite those, never these notes.
